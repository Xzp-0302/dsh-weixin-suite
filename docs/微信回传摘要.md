DeepSeek Harness 微信插件说明：

需求：做独立、可发布的原生微信插件，覆盖腾讯公开个人微信 iLink 能力；当前 Codex 微信桥接保持原样。

方案：微信 iLink 收发层连接 Harness Agent，通过原生工具发送文字、图片、文件、视频和语音；独立管理账号、会话、凭证和任务队列。

范围：扫码及配对、多账号、消息与附件双向传输、引用、输入状态、远程审批和多题回答、停止、新会话、断线重连、人工重试。

交付：dsh-weixin-suite 0.1.0-rc.1 源码、需求方案、能力矩阵、三轮审查记录、验收清单、发布指南与市场索引生成脚本。

状态：源码已实现并完成静态审查；按要求未安装运行、未测试、未扫码、未发送、未发布。微信媒体权限、语音上行和手机展示等需验收后确认，不能宣称已实测可用。

环境：Node.js 24.9+，参考 Harness 0.2.1-rc.3；已有可用模型和 preset，可访问微信接口/CDN；语音编解码使用可选 silk-wasm，其他音频转换可配置 FFmpeg。
