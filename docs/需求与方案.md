# DeepSeek Harness 微信插件：需求与实施方案

日期：2026-10-28。项目：dsh-weixin-suite。版本：0.2.0-rc.1。

追加需求已实现：Git 安装后通过 DSH 原生侧栏进入微信助理，在页面管理会话、扫码绑定及设置。无需首次使用 CLI 登录和 YAML 配置；技术结构见 DASHBOARD.md。实际加载仍待用户验收。

## 用户要求

实现可供用户验收、随后自行发布到 DeepSeek Harness 插件市场的独立插件。覆盖腾讯当前公开个人微信 iLink 协议的能力。暂不执行测试，通过反复静态代码审查排查问题。关键进度应及时说明。现有微信 × Codex 桥接程序、进程、登录凭证和私有状态均不改动、不复用。

## 能力范围

- 扫码登录、配对数字、登录重定向、二维码过期和已有绑定处理。
- 多账号与账号内私聊隔离，默认仅允许扫码用户；本地管理命令可授权其他私聊用户。
- 文字、图片、普通文件、视频、语音的收发。音频转语音使用可选 SILK 编解码组件；复杂音频格式使用用户自行安装的 FFmpeg。
- 附件上传地址申请、AES 加密、CDN 上传/下载、下载解密、大小和文件名校验。
- 引用消息及有限本地引用缓存、微信侧语音转写、输入状态、连接启动/停止通知。
- 在微信中与 Harness Agent 对话，处理权限审批和多题/多选提问，查看状态、新会话、停止和人工重试。
- 原生模型工具：发送消息与附件、查询状态、控制输入状态。
- 接收去重、持久化队列、任务取消、断线重连、会话恢复；发送结果未知时不自动重发。
- 市场组合包、独立账号管理命令、中文说明、能力矩阵、发布指南和人工验收清单。

“腾讯支持”指本项目固定参考版本公开客户端已定义的个人微信 iLink 协议能力，不包含企业微信、公众号、朋友圈、通讯录或未公开的群聊能力。协议存在字段不等于服务端对所有账号都开放；语音发送、工具状态消息及账号媒体权限需要用户验收确认。

## 实现结构

微信 → 独立 iLink 收发层 → 账号/私聊路由 → Harness 原生 Agent → 注册工具 → 微信消息或附件。

- api.js：扫码、长轮询、发消息、上传地址、输入状态、生命周期通知。
- media.js / voice.js：附件处理、SILK 及可选 FFmpeg 转码。
- store.js / security.js：独立持久化、进程锁、路径与网络地址校验。
- channel.js：消息路由、任务队列、发送记录、连接和取消。
- harness.js / interactions.js / tools.js：Harness 会话、审批、提问和工具。
- index.js：Cordis 注册、配置与插件卸载清理。
- bin/cli.js：独立扫码登录和账号管理。

## 环境和发布条件

目标参考版本为 DeepSeek Harness 0.2.1-rc.3，Node.js 24.9+。需要已经能正常使用的 Harness 配置、模型提供方和 Agent preset。电脑可访问微信 iLink 和微信 CDN 的 HTTPS 地址；无需额外公网端口、域名或服务器。用户为插件单独扫码绑定机器人，不能导入本机其他桥接程序的账号凭证。

插件通过 dsh.bundle.patch 注册，无需修改全局配置。源码纯 ESM JavaScript，不需要编译后才能安装；市场发布前需确定包名归属、作者、仓库地址、正式版本并完成用户验收。当前不执行安装、扫码、发送、功能测试或市场发布。
