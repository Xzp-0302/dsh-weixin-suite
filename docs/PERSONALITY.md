# 语气与个性化

当前版本：0.1.0-rc.1。

在微信助理 → 设置 → 语气与个性化中配置，使用页面底部“保存设置”统一保存。默认采用 OpenClaw 风格搭档：直接、自然、有判断、少客套；也可选择温暖、专业、简洁或自定义。选择“完全沿用 DSH 预设”会停止注入本插件个性化，其他字段仍保留以便切换回来。

可配置助理和用户称呼、回复语言、回复长度、幽默程度和表情使用。示例：助理叫“小舟”，称呼用户“老张”，简体中文、简短回复、自然幽默、少量表情。当前任务的具体表达要求优先于这些默认值。

## OpenClaw 配置思路

参考 [OpenClaw 官方 SOUL 指南](https://docs.openclaw.ai/concepts/soul) 的人格与语气分层，提供手动填写或粘贴 Markdown 内容的字段：

| 字段 | 用途 | 上限 |
|---|---|---|
| SOUL.md | 语气、表达方式、沟通偏好，例如“先说结果，技术问题给最短可用步骤” | 6000 字符 |
| IDENTITY.md | 助理身份描述，例如“叫小舟，是我的技术搭档” | 2000 字符 |
| USER.md | 你主动提供的背景与偏好，例如“主要使用 Windows，希望示例用 PowerShell” | 3000 字符 |

这是独立实现的风格适配，不引入 OpenClaw 运行时，也不宣称跨模型获得完全一样的语气。不会自动扫描 OpenClaw、其他插件或 Codex 的配置文件；已有内容可自行复制粘贴。不要填写密钥。用户画像是偏好背景，不会自动产生任务或额外授权。

## 保存、预览与恢复

“预览风格指令”展示当前草稿将产生的文本，不调用模型、不保存、不发送微信。“重置个性化草稿”只恢复个性化字段，保留目录、模型等其他草稿；之后点击保存才生效。每个字段的 `!` 支持悬停与键盘聚焦查看说明。

正在执行任务时需先停止或等待完成再保存。保存后由每次提示词组装时读取配置，对本插件既有及新建微信会话的后续回复生效；无需重置历史或重复注册提示词。其他普通 DSH 会话不注入该个性化。文字保存在本插件独立 settings.json，模型推理时相关内容会随上下文交给所选模型。

更换 preset、模型与个性化不是同一项设置：模型/preset 仍按原流程对新会话生效。人格只影响沟通偏好，不更改文件目录、审批、发送对象和其他权限限制。

## 待验收

选择每种预设并保存、在既有微信会话观察后续语气、自定义 Markdown 及字面双花括号、字符边界、重启恢复、草稿预览与重置、沿用 DSH 后确认不再注入、普通桌面会话隔离，以及连续禁用/启用后的提示词清理。本版按用户要求未运行功能测试；实际语气由所用模型决定。
