# 用户人工验收清单（尚未执行）

准备独立 Harness profile、独立状态目录和专用微信机器人。不要关闭、重绑或复用原 Codex 桥接的机器人。先完成静态审查记录中列出的运行时验证，再决定是否发布。

## 1. 安装和生命周期

- Node 24.9+，目标 Harness 0.2.1-rc.3；安装依赖后组合包能被识别。
- 中文/英文名称、描述和图标在 Harness 中正确显示；设置字段可用。
- 没有账号时能加载并说明未绑定，不产生循环错误。
- 同一状态目录第二个进程被锁阻止；停用后锁释放，重新启用能恢复。
- 异常退出后 unlock 只允许清除死亡进程的锁；活动进程不可解锁。
- 停用时取消轮询、任务、提问与输入状态，卸载发送工具，不遗留 Promise 拒绝或进程。

## 2. 登录与账号

- 普通扫码、配对数字、二维码过期重试、登录重定向、已有绑定分别验证。
- 两个不同机器人账号均能收发，彼此会话、审批编号和附件隔离。
- 未授权私聊和群消息不能发起任务；增加/移除额外用户后权限正确。
- 重新扫码本插件账号不会复用旧会话上下文；logout 不影响其他本插件账号。
- 原 Codex 桥接仍能正常对话，代码及私有状态没有被本插件操作。

## 3. 消息和文件

- 普通中英文、emoji、多段长文完整到达；没有截断或乱序。
- 微信发图片，Harness 形成有效图片附件；文本模型有明确能力限制。
- 手机发 PDF/Word/ZIP，能保存并由 Agent 读取；再将允许目录中的原文件发回。
- MP4 双向收发，手机能下载/播放；视频以附件传给 Agent。
- 引用文字、引用已发送文件、只有引用 ID 的消息都能得到合理上下文。
- 中文文件名、空文件、超限文件、目录路径、特殊设备名、越界路径和符号链接替换按约定处理。
- 超过本地上限时不上传；CDN HTTP 错误、缺少 x-encrypted-param、错误密钥、错误长度/MD5均不能误报成功。
- 手机端下载收到的 PDF，核对文件字节或哈希，确认能打开。

## 4. 语音

- 微信语音原音频和服务器转写能到达 Harness；无转写时不能凭空生成文字。
- SILK 可选组件安装时能解码为 WAV；未安装时原始音频仍能保存。
- 标准 24kHz 单声道 16-bit WAV 编码为 SILK 并发送；手机显示与播放正确。
- 配置 FFmpeg 后验证 MP3/立体声 WAV；转换超时、取消、超出时长均可结束。
- 若腾讯拒绝语音上行，把该能力标记服务端不可用，普通音频文件发送仍可用。

## 5. 任务和人机交互

- 多轮消息保持同一会话，/新会话 后隔离旧上下文；重启能恢复原会话。
- 运行期间继续收消息并排队；/停止 可立即取消，等待任务不会继续执行。
- 敏感操作的审批只由正确聊天内的 /批准 编号 授予一次；拒绝、超时、过期编号不能授权。
- 多题、多选、自由文字回答；错误序号可纠正后重答。
- Harness 定时提问到期后继续任务，仍能通过原编号补答；会话重启后补答状态正确。
- 桌面 Agent 显式指定账号发送时使用 Harness 审批，不能任意选择其他收件人。
- progress=true 能在微信看到关键过程文字；progress=false 不遗漏最终回答；toolEvents 单独验证兼容性。

## 6. 故障恢复

- 断网后退避重连，恢复后不重复执行已接收消息。
- 上传完成、发消息前故障；发送请求过程中故障；收到响应但状态写盘前故障分别验证。
- unknown 发送结果不自动重发；用户自行确认后再发起新操作。
- 重启时 queued/running 标记 interrupted，不自动重跑；/状态 可查、/重试 明确执行、/清理中断 可清理。
- 状态文件损坏、磁盘满、不可写时不会继续无记录执行。
- 登录失效停止该账号，并能在本机重新绑定。

验收记录应附：环境版本、实际微信客户端版本、各项通过/失败/不适用、必要的脱敏证据。不要提供 token、二维码原链接、上下文票据或完整私有状态文件。
