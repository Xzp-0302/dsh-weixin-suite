# DSH 微信助理

[![Version](https://img.shields.io/badge/version-0.1.0--rc.1-blue)](https://github.com/Xzp-0302/dsh-weixin-suite/releases)
[![License: MIT](https://img.shields.io/badge/License-MIT-green.svg)](LICENSE)

通过个人微信使用 DeepSeek Harness：交代任务、发送图片和文档、接收回复与文件，并在 DSH 侧栏统一管理账号、会话和个性化设置。

`dsh-weixin-suite` 基于微信 iLink 协议，使用 DSH 原生 Agent、模型配置、审批和会话界面。无需独立管理服务或公网入站端口。

## 功能

- **原生管理界面**：左侧“微信助理”入口，包含概览、已有会话、账号与绑定、设置。
- **扫码绑定**：二维码与配对数字登录，支持多账号、暂停、恢复及移除本地绑定。
- **消息与附件**：文字、图片、文件、视频收发；语音接收与可选 SILK 语音发送；支持引用消息。
- **远程任务**：独立微信会话、进度回复、任务停止、上下文重置、重启恢复与人工重试。
- **审批与提问**：在微信或管理页面批准操作、拒绝操作、回答问题及多选题。
- **模型选择**：读取 DSH 已配置的供应商和模型，支持下拉选择、自定义输入或使用默认路由。
- **语气与个性化**：OpenClaw 风格搭档、温暖、专业、简洁及自定义风格；支持称呼、语言、篇幅、幽默、表情与人格内容。
- **页面更新**：检查 GitHub 版本标签、选择版本并确认更新，由 DSH 管理器自动替换，失败时尝试恢复原版本。
- **独立数据**：账号凭证、消息状态和页面设置独立保存，发送文件按授权目录控制。

## 环境要求

| 项目 | 要求 |
|---|---|
| Node.js | 24.9.0 或以上 |
| DeepSeek Harness | `>=0.2.1-rc.3 <0.3.0`，启用 Agent 和 preset 服务 |
| 模型 | DSH 中已有可用的供应商、模型与默认预设 |
| 网络 | 可访问微信 iLink 接口及微信 CDN；Git 安装和更新需要访问 GitHub |
| 可选组件 | `silk-wasm` 用于 SILK 编解码；FFmpeg 用于其他音频格式转换 |

## 安装

在 DSH 原生插件管理中通过 Git 地址安装并启用：

```text
git+https://github.com/Xzp-0302/dsh-weixin-suite.git#v0.1.0-rc.1
```

也可以使用命令行，`desktop` 替换为实际使用的 profile：

```powershell
dsh plugin --profile desktop add "git+https://github.com/Xzp-0302/dsh-weixin-suite.git#v0.1.0-rc.1"
```

安装后打开左侧 **微信助理**。日常操作均在页面完成，不需要预先执行命令行登录、复制令牌或手写 YAML。

## 快速开始

1. 打开 **账号与绑定**，点击 **绑定微信**，使用手机扫码；如需配对数字，在页面输入。
2. 从微信向助理发送一条消息。
3. 在 **已有会话** 查看近期消息、审批和问题，或点击 **在 DSH 中打开** 查看完整会话。
4. 需要发送本机已有文件时，在 **设置** 中添加允许发送的文件夹，例如 `D:\study`。

例如，在微信发送：

> 找到 D:\study 下的容器学习 PDF，把文件发给我。

助理通过 `weixin_send` 工具发送实际附件。授权目录以外的文件不能发送；仅回复本地路径不代表文件已经送达。

## 模型与个性化

在 **设置** 中选择已有供应商和模型，也可在对应输入框填写自定义 ID。两项同时留空时沿用 DSH 默认路由；模型和 preset 变更对新会话生效。

**语气与个性化** 提供以下设置：

| 设置 | 说明 |
|---|---|
| 语气风格 | OpenClaw 风格搭档、温暖体贴、专业严谨、简洁利落、自定义、完全沿用 DSH |
| 助理与用户称呼 | 助理名称以及希望助理如何称呼你 |
| 回复偏好 | 语言、默认长度、幽默程度、表情使用 |
| SOUL.md 内容 | 语气与表达习惯，可填写或粘贴 Markdown |
| IDENTITY.md 内容 | 助理人格与身份描述 |
| USER.md 内容 | 主动提供的背景与个人偏好 |

默认 OpenClaw 风格强调直接、自然、有判断、少客套。可以预览风格指令、重置个性化草稿，然后统一保存。保存后对微信会话的后续回复生效，不需要重置聊天历史；选择“完全沿用 DSH 预设”可关闭本插件的个性化覆盖。

人格字段不自动读取其他应用文件。其内容会随微信会话上下文交给所选模型，适合填写沟通偏好，不应填写密钥。风格配置不改变文件访问、审批或发送权限。详情见 [个性化说明](docs/PERSONALITY.md)。

## 常用设置

配置项旁的 `!` 提供说明与示例，可通过鼠标悬停或键盘聚焦查看。数值字段提供默认值，并标明范围和必填要求。

| 设置 | 默认值 | 用途 |
|---|---|---|
| 额外发送目录 | 空 | 为空时仅允许助理工作目录；每行添加一个绝对路径 |
| 附件大小上限 | 20 MiB | 本地限制，可配置 1–200 MiB |
| 进度回复 | 开启 | 将任务进度发到微信 |
| 任务超时 | 30 分钟 | 超时后取消当前聊天任务 |
| 回答等待时间 | 300 秒 | 审批及提问等待时间 |
| 语音时长上限 | 60 秒 | 本地语音长度限制 |
| FFmpeg 路径 | 空 | 音频格式转换所用的可执行文件绝对路径 |
| 协议工具状态 | 关闭 | 根据账号支持情况选择是否发送工具状态消息 |

高级部署字段 `stateDir`、`workspace`、`accountIds` 在 DSH 原生插件配置中管理。通常无需修改。页面设置保存在本插件的 `settings.json`，优先于同名基础配置；正在执行任务时，请先停止或等待任务完成再保存。

## 微信命令

| 命令 | 功能 |
|---|---|
| `/帮助` | 查看可用命令 |
| `/状态` | 查看账号、任务状态和中断消息编号 |
| `/停止` | 取消当前任务并清空当前聊天的等待队列 |
| `/新会话` | 空闲时重置上下文，下一条消息使用新会话 |
| `/重试 消息编号` | 手动重试失败或中断任务 |
| `/清理中断` | 清除中断记录，不重新执行任务 |
| `/批准 编号`、`/拒绝 编号` | 对操作作出一次性决定 |
| `/回答 编号 答案` | 回答问题；多题用 `|`，多选序号用逗号分隔 |

重试可能重复任务已发生的操作，请确认后使用。一般任务直接发送普通文字，无需添加命令前缀。

## Agent 工具

| 工具 | 功能 |
|---|---|
| `weixin_send` | 发送文字或授权目录中的图片、文件、视频、语音 |
| `weixin_status` | 查询账号状态、发送限制及引用缓存 |
| `weixin_sessions` | 查询微信会话列表 |
| `weixin_typing` | 设置当前微信聊天的输入状态 |

微信会话固定回复对应私聊；其他 DSH 会话发送微信时需指定账号并通过原生审批。发送返回 `accepted` 表示网关受理，结果未知时不会自动重复发送。

## 更新

打开 **微信助理 → 设置 → 插件更新**，检查已发布标签，选择目标版本并确认。更新由 DSH 管理器执行，不需要手动卸载；微信账号、页面设置和附件目录独立保存。

更新前结束任务并取消扫码。更新期间页面会短暂断开，详细进度和失败原因可在 DSH 插件管理查看。若新版本安装或激活失败，会尝试从原来源恢复。详情见 [更新说明](docs/UPGRADING.md)。

## 数据与访问控制

默认只接受扫码用户的私聊消息。凭证和消息状态保存在按 profile 分隔的独立目录，POSIX 使用受限文件权限，Windows 配置当前用户及 SYSTEM 的目录权限。

文件发送核验真实路径、允许目录、文件大小及读取前后变化，并拒绝发送插件私有状态、常见凭证目录和环境密钥文件。重启后未完成任务标记为中断，不自动重跑。

本项目适配个人微信 iLink 协议。群聊、朋友圈、通讯录、公众号及企业微信属于不同能力范围；媒体大小、语音及协议工具状态还受微信服务端和账号支持情况限制。图片和视频理解取决于所选模型；FFmpeg 不随本项目分发。
